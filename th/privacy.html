สารบัญ

ภาพถ่ายและสิทธิ์เข้าถึงข้อมูลการใช้งานและข้อมูลทางเทคนิคบริการของบุคคลที่สามโฆษณาและตัวเลือกความเป็นส่วนตัวการซื้อและการช่วยเหลือการเปิดเผยและการประมวลผลข้ามประเทศการเก็บรักษาและการลบสิทธิของคุณ เด็ก และความปลอดภัยเว็บไซต์นี้และการเปลี่ยนแปลง

ภาพถ่ายและสิทธิ์เข้าถึง

Slidecut ใช้แบ่งภาพและส่งออกภาพให้เหมาะกับแพลตฟอร์มต่าง ๆ ภาพถ่ายและภาพที่สร้างทั้งหมดประมวลผลบนอุปกรณ์ของคุณเท่านั้น เนื้อหาภาพจะไม่ถูกอัปโหลดไปยังเซิร์ฟเวอร์ของเราหรือของบุคคลที่สามโดยเด็ดขาด และไม่รวมอยู่ในรายงาน Firebase หรือ Umeng การเข้าถึงจำกัดตามภาพที่เลือกหรือสิทธิ์ที่อนุญาต การบันทึกอาจต้องใช้สิทธิ์เพิ่มภาพในคลัง คุณเปลี่ยนสิทธิ์ได้ในการตั้งค่า iOS

ข้อมูลการใช้งานและข้อมูลทางเทคนิค

เราใช้ Firebase และ Umeng สำหรับสถิติตัวระบุอุปกรณ์และการวินิจฉัยแอปขัดข้อง บริการเหล่านี้ประมวลผลตัวระบุอุปกรณ์หรืออินสแตนซ์แอปและข้อมูลการขัดข้อง เพื่อค้นหาปัญหาและปรับปรุงความเสถียร รายงานอาจมีข้อมูลวินิจฉัย เช่น รุ่นอุปกรณ์ เวอร์ชันระบบและแอป เวลาที่ขัดข้อง และข้อมูลลำดับการเรียกใช้ การเชื่อมต่อ SDK อาจสร้างบันทึกทางเทคนิค เช่น ที่อยู่ IP ด้วย ไม่มีการเก็บหรืออัปโหลดเนื้อหาภาพผ่านบริการเหล่านี้ เราไม่ถือว่าตัวระบุเป็นข้อมูลนิรนามเพียงเพราะไม่มีชื่อของคุณ

บริการของบุคคลที่สาม

Firebase ให้บริการโดย Google ส่วน Umeng ใช้สำหรับสถิติตัวระบุอุปกรณ์และวินิจฉัยแอปขัดข้อง Google AdMob (Google Mobile Ads SDK) ให้บริการโฆษณาภายในแอป ลิงก์ความเป็นส่วนตัวอย่างเป็นทางการอยู่ด้านล่าง บริการเหล่านี้ไม่ได้รับภาพถ่ายของคุณ เรากำหนดให้ผู้ประมวลผลแทนเราคุ้มครองข้อมูลตามนโยบายและข้อกำหนดที่ใช้บังคับ ผู้ให้บริการอาจประมวลผลตามนโยบายของตนเพื่อความปลอดภัยและวัดผลโฆษณา แต่ไม่แทนที่ความรับผิดชอบของเรา

โฆษณาและตัวเลือกความเป็นส่วนตัว

แอปใช้ Google AdMob เพื่อแสดงโฆษณาที่มีให้บริการ เช่น แบนเนอร์ โฆษณาคั่นระหว่างหน้า หรือแบบให้รางวัล ขึ้นอยู่กับการตั้งค่า SDK สิทธิ์ และความยินยอม Google อาจประมวลผลตัวระบุอุปกรณ์หรือแอป รวมถึงตัวระบุโฆษณาเมื่อได้รับอนุญาต ที่อยู่ IP และพื้นที่โดยประมาณที่อนุมานจาก IP การแสดงและโต้ตอบกับโฆษณา ตลอดจนข้อมูลขัดข้องหรือประสิทธิภาพ เพื่อแสดง วัดผล และป้องกันการทุจริต ไม่ส่งภาพถ่ายให้ AdMob โดยเด็ดขาด การติดตามที่เข้าเกณฑ์ต้องได้รับสิทธิ์ App Tracking Transparency ของ Apple และการประมวลผลทางเลือกที่ต้องขอความยินยอมต้องอาศัยความยินยอมนั้น คุณเปลี่ยนสิทธิ์ในการตั้งค่า iOS ใช้ตัวควบคุมความยินยอมที่แอปแสดง หรือติดต่อเราเพื่อถอนความยินยอมและคัดค้านการประมวลผลทางเลือกได้ การปฏิเสธติดตามไม่ยกเลิกฟีเจอร์ที่ซื้อ ดูนโยบายและตัวเลือกโฆษณาของ Google ด้านล่าง

การซื้อและการช่วยเหลือ

Apple ประมวลผลการชำระเงินผ่าน App Store แอปอาจใช้ตัวระบุธุรกรรมและสถานะการซื้อเพื่อปลดล็อกหรือกู้คืน Premium เราไม่ได้รับข้อมูลบัตรทั้งหมดของคุณ หากส่งอีเมลถึงเรา เราจะได้รับที่อยู่อีเมล ข้อความ และไฟล์แนบ เพื่อใช้ตอบกลับและแก้ปัญหา โปรดอย่าส่งภาพที่ละเอียดอ่อนหรือข้อมูลส่วนบุคคลที่ไม่จำเป็น

การเปิดเผยและการประมวลผลข้ามประเทศ

Firebase, Umeng และ Google AdMob ประมวลผลข้อมูลตามวัตถุประสงค์ที่อธิบายไว้ เราอาจเปิดเผยข้อมูลเมื่อกฎหมายกำหนดหรือจำเป็นเพื่อคุ้มครองสิทธิอันชอบด้วยกฎหมาย ผู้ให้บริการอาจประมวลผลนอกประเทศที่คุณอาศัยผ่านโครงสร้างพื้นฐานที่ระบุในนโยบายของตน หากกฎหมายกำหนดมาตรการคุ้มครองการโอนข้ามประเทศหรือความยินยอมแยกต่างหาก ให้เป็นไปตามข้อกำหนดนั้น ตัวระบุไม่ได้เป็นข้อมูลนิรนามเพียงเพราะไม่มีชื่อ

การเก็บรักษาและการลบ

ภาพในคลังรูปภาพคงอยู่จนกว่าคุณจะลบ การถอนการติดตั้งไม่ลบภาพหรือข้อมูลสำรองของอุปกรณ์ โดยทั่วไปจะลบข้อมูลในพื้นที่แยกของแอป ทั้งนี้ขึ้นอยู่กับกลไกจัดเก็บและสำรอง iOS ตัวระบุอุปกรณ์และบันทึกวินิจฉัยหรือโฆษณาเก็บเท่าที่จำเป็นสำหรับวัตถุประสงค์ที่แจ้ง ภายใต้การตั้งค่าผู้ให้บริการ นโยบายที่เผยแพร่ และหน้าที่ตามกฎหมาย ข้อมูลที่เราควบคุมจะถูกลบหรือทำให้ไม่สามารถระบุตัวตนเมื่อไม่จำเป็น ยกเว้นกฎหมายกำหนดให้เก็บ อีเมลช่วยเหลือเก็บเท่าที่จำเป็นต่อคำขอและหน้าที่ตามกฎหมาย ติดต่อ wrzxnx@gmail.com เพื่อขอลบหรือสอบถามการเก็บข้อมูล เราจะแจ้งข้อยกเว้นที่ชอบด้วยกฎหมาย การถอนการติดตั้งไม่ลบบันทึกที่ผู้ให้บริการเก็บไว้โดยอัตโนมัติ

สิทธิของคุณ เด็ก และความปลอดภัย

ตามกฎหมายที่ใช้บังคับ คุณอาจขอเข้าถึง สำเนา แก้ไข ลบ จำกัดหรือคัดค้านการประมวลผล ถอนความยินยอม และร้องเรียนต่อหน่วยงานกำกับได้ โปรดติดต่อ wrzxnx@gmail.com เราอาจขอยืนยันตัวตนอย่างเหมาะสม แอปไม่ได้มุ่งให้บริการเด็กที่อายุต่ำกว่าเกณฑ์ยินยอมทางดิจิทัลในพื้นที่ หากเชื่อว่ามีการเก็บข้อมูลเด็กอย่างไม่เหมาะสม โปรดติดต่อเรา เราใช้มาตรการคุ้มครองที่สมเหตุสมผล แต่ไม่อาจรับรองความปลอดภัยได้ทั้งหมด

หน้าเว็บนี้ไม่มี SDK วิเคราะห์ สคริปต์โฆษณา หรือแบบอักษรจากภายนอก เว็บไซต์โฮสต์บน GitHub Pages และ GitHub อาจประมวลผลข้อมูลการเชื่อมต่อ เช่น IP และบันทึกเซิร์ฟเวอร์ ตามประกาศความเป็นส่วนตัวของตน การเปลี่ยนภาษาไม่ต้องมีบัญชี เมื่อแก้ไขนโยบาย เราจะปรับวันที่ด้านบนและแจ้งการเปลี่ยนแปลงสำคัญตามกฎหมาย ความแตกต่างในการแปลไม่จำกัดสิทธิที่กฎหมายท้องถิ่นคุ้มครองโดยบังคับ
